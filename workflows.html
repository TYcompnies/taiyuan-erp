〇職務與角色總覽

系統管理員 admin 全部權限・系統維護 業務（銷售） sales 訂單・客戶・銷退 倉管 warehouse 出入庫・庫存 會計 accounting 账款・傳票・報表 全員 儀表板・出勤打卡

系統另內建「管理者」角色（日常業務+報表全部權限、不含系統設置）。各角色權限可由系統管理員於「角色管理／權限管理」中調整。

一首頁 Dashboard（登入後首屏）

所有職務登入後皆進入首頁；選單與快捷操作依角色權限自動顯示，未授權的功能自動隱藏。

全員① 登入系統輸入帳號密碼（如 admin / sales / warehouse / accounting）
系統② 依角色載入選單權限校驗：無權限的功能不顯示、直接輸入路由會被擋回首頁
全員③ 查看首頁 KPI本月營收 / 毛利 / 應收 / 應付 / 庫存價值（皆折算本位幣人民幣）
全員④ 點擊快捷操作依權限顯示 12 個快捷入口，點擊直達對應功能頁

首頁 KPI 指標卡（全員可見，數字自動聯動）

本月營收按出貨日期歸屬・外幣×匯率
銷貨成本出貨數量×換算率×成本
本月毛利／淨利營收−成本−費用
應收賬款未收淨額（扣退貨沖銷）
應付賬款未付淨額（扣退回沖銷）
庫存價值按採購幣別匯率折本位幣
低庫存提醒低於安全庫存清單（倉管關注）
負庫存警示缺貨商品即時提醒（倉管關注）

二銷售循環：接單 → 出貨 → 收款（核心業務流程）

三個職務接力：業務接單 → 倉管出貨 → 會計收款；每一步自動更新庫存、賬款與會計傳票。

業務
sales
① 建立客戶/商品主檔首次交易前：客戶主檔（幣別/付款條件）、商品主檔（售價/換算率）
② 新增銷貨訂單選客戶→自動帶入幣別/付款條件→加明細行（數量×單價即時算合計）→存為草稿
▼
倉管
warehouse
③ 訂單出貨銷貨訂單列表→「出貨」→選倉庫/物流方式/物流單號→確認
④ 系統自動處理校驗庫存（不足拒絕並提示需求量）→ 扣庫存×銷售換算率 → 生成出貨單 → 自動傳票（借：應收賬款／貸：主營業務收入）→ 訂單轉「已出貨」
⑤ 列印出貨單出貨單列表/詳情均可列印（A4 格式・人民幣大寫）隨貨交付
▼
會計
accounting
⑥ 應收賬款查詢應收賬款頁：未收 = 應收 − 已收 − 退貨沖銷；外幣自動折本位幣顯示
⑦ 收款登記輸入金額/方式/日期（超收自動拒絕）→ 可分多次收款
⑧ 系統自動處理自動傳票（借：庫存現金／貸：應收賬款）→ 訂單狀態轉 部分收款/已收清
▼
業務
退貨處理
⑨ 銷貨退回/折讓（如需）選原訂單→自動帶出明細→填退回數量（超退限制）
⑩ 系統自動處理庫存回補×換算率 + 應收沖減 + 成本沖回 → SRET 傳票；已有銷退記錄的出貨單禁止刪除
⑪ 月底結算（會計）損益表：收入按出貨日期歸屬，退貨按退回日期沖減

三採購循環：下單 → 進貨 → 付款

管理者/管理員建立採購單 → 倉管進貨入庫 → 會計付款沖賬。

管理者
/管理員
① 建立供應商主檔幣別、付款條件、聯絡資訊（供應商主檔由管理者維護）
② 新增採購單選供應商→自動帶入幣別/付款條件→加明細行→保存草稿
▼
倉管
warehouse
③ 進貨入庫採購單列表→「進貨」→確認彈窗→選入庫倉庫
④ 系統自動處理庫存增加×採購換算率（如 1 箱=10 個）→ 自動傳票（借：庫存商品／貸：應付賬款，外幣×匯率折本位幣）→ 狀態轉「已進貨」；重複進貨會被攔截
▼
會計
accounting
⑤ 應付賬款查詢未付 = 應付 − 已付 − 退回沖銷；外幣折本位幣顯示
⑥ 付款登記金額/方式/日期（超付拒絕），可分多次付款
⑦ 系統自動處理自動傳票（借：應付賬款／貸：庫存現金）→ 狀態轉 部分付款/已付清
▼
退回處理
⑧ 採購退回/折讓（如需）管理者登記：選原採購單→帶出明細→填退回數量
⑨ 系統自動處理庫存扣減×換算率 + 應付沖減 → PRET 傳票

四庫存管理（倉管負責）

庫存調整流程（盤點差異 / 拆包組包）

倉管① 新增調整單庫存調整→新增→選倉庫
倉管② 選商品填數量正數入庫/負數出庫，標註庫存單位
系統③ 即時預覽異動前/異動後庫存自動預覽
系統④ 過賬生效庫存更新 + ADJ 自動傳票；刪除時按 −數量反向沖銷

庫存報表（倉管/業務/會計均可查）

依權限庫存總覽全部啟用商品（含 0 庫存）× 各倉庫數量與價值，標註庫存單位
依權限安全庫存報表負庫存「缺貨」/ 不足「+N」/ 充足「0」三色提示
倉管首頁低庫存提醒低於安全庫存、負庫存商品即時清單，點擊直達

五賬款與財務（會計負責）

日常賬務流程

會計① 應收/應付盯賬每日查未收/未付淨額（自動扣退貨沖銷、外幣折本位幣）
會計② 收款/付款登記在訂單/採購單上直接登記，金額/方式/日期
會計③ 費用支出登記房租/物流/平台費等，選會計科目→自動 EXP 傳票
會計④ 手工傳票（如需）傳票作業→新增（僅「未過賬」）→借貸平衡→過賬；已過賬禁刪

報表產出（月底結算）

會計總分類賬科目別明細賬
會計試算表借貸平衡自動校驗
會計資產負債表資產=負債+權益
會計損益表收入−成本−費用=淨利（收入按出貨日歸屬）

7 種業務事件（出貨/進貨/收款/付款/費用/銷退/採退/庫存調整）皆自動生成已過賬傳票，會計無需重複切票；刪除單據時傳票自動作廢。

六基本資料建立流程（系統初始化 / 新資料維護）

首次啟用建議按以下順序建立（前者為後者的前置資料）；批量資料可用 Excel 導入中心（管理員）。

管理員① 基礎設置倉庫→單位→幣別（本位幣唯一）→商品分類→付款條件→物流方式
業務② 商品主檔編碼/售價/銷售換算率/安全庫存/庫存單位（業務與倉管均可維護）
業務③ 客戶主檔幣別/付款條件（下單時自動帶入）
管理者④ 供應商主檔幣別/付款條件（採購時自動帶入）
管理員⑤ Excel 批量導入導入中心：商品/客戶等主檔批量導入

付款條件保存後自動同步到既有客戶/供應商的付款方式與天數；幣別匯率變動即時影響折本位幣金額。

七出勤管理（全員打卡）

全員① 進入出勤管理ERP 選單「出勤管理」（內嵌頁面）或「新視窗打開」
全員② 獨立登入出勤系統自有帳號（初始 admin/admin123），與 ERP 帳號體系獨立
全員③ WiFi 打卡上下班基於 WiFi 網路打卡，自動記錄出勤/迟到/早退
管理員④ 維護與雲同步員工/班次/報表維護；數據存獨立空間，與 ERP 業務數據完全隔離

八系統設置（系統管理員專責）

管理員① Excel 導入中心歷史資料批量遷移（商品/客戶/供應商）
管理員② 系統備份定期下載備份檔；可恢復；「清空業務數據」危險操作留基礎資料
管理員③ 雲端同步配置 textdb.online / GitHub 雙供應商；AES 加密；多設備 LWW 合併；修改 3 秒後自動上傳
管理員④ 用戶/角色/權限開通員工帳號→分配角色→微調權限；禁刪最後管理員
